# Face Anti-Spoofing System

A Face Anti-Spoofing System developed using **Python** and **Computer Vision** techniques to distinguish between real human faces and spoofing attacks such as photos displayed on mobile devices or printed images. The system enhances biometric authentication by ensuring that only live users can access the application.

## ✨ Features

* 👤 Real-time face detection and recognition
* 🛡️ Face anti-spoofing to detect fake faces
* 🔐 Secure login and registration system
* 📷 Live webcam-based authentication
* 🤖 Machine Learning-based spoof detection
* 📊 Dataset collection and preprocessing utilities
* 🎯 Trained models for liveness detection

## 🚀 Getting Started

### Prerequisites

* Python 3.8+
* Webcam

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Y45hK1r0l4/Face-Anti-Spoofing-System.git
cd Face-Anti-Spoofing-System
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python main.py
```

## 🧠 How It Works

1. The system captures facial data using a webcam.
2. Face detection identifies the user's face in real time.
3. The anti-spoofing model analyzes facial features to determine whether the face is live or spoofed.
4. Access is granted only when a genuine face is detected.
